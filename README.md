# Justikets - Online Movie Ticket Booking Application

## Project Overview
Manual Testing project for an Online Movie Ticket Booking Application.

## Modules Tested
- Login
- Movie Search
- Seat Selection
- Payment
- Booking Confirmation

## Testing Types Performed
- Smoke Testing
- Functional Testing
- Integration Testing
- System Testing
- Regression Testing
- Sanity Testing
- Browser Compatibility Testing (Chrome, Firefox, Microsoft Edge)
- Aesthetic Testing

## Test Artifacts
- Test Scenarios
- Test Cases (50+)
- Bug Report
- Test Summary Report

## Tools Used
- JIRA (Defect Tracking)
- Microsoft Excel (Test Cases)
- Browser DevTools

## Defect Reporting
Defects logged with Severity and Priority classification.
